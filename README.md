# 메모정리장

메모, 할 일, 캘린더를 **한 화면에서** 관리하는 개인용 웹앱입니다.
회원가입 없이 브라우저에서 바로 쓰고, 데이터는 내 브라우저 안에만 저장됩니다.

> 현재 **1단계(AI 없음)** 까지 만들어져 있습니다. 설계 내용은 [PRD.md](PRD.md)에 있습니다.

**접속 주소: https://memo-three-brown.vercel.app** (Vercel 배포)

## 기능

| 구분 | 내용 |
|---|---|
| 메모 | 작성·수정·삭제, 최신순 카드 목록, 제목·내용 검색 |
| 할 일 | 추가·완료 체크·수정·삭제, 마감일(D-day 표시), 기한 지남·오늘·예정·마감 없음·완료로 묶어 보기, 필터 |
| 캘린더 | 월간 달력, 날짜별 일정 추가·삭제, 날짜를 눌러 일정·할 일 함께 보기 |
| 연결 | 마감일을 정한 할 일이 캘린더에 점으로 표시됨 |
| 요약 | 오늘 마감 · 기한 지남 · 남은 할 일 숫자 |
| 저장 | 추가·수정·삭제할 때마다 자동 저장 |
| 화면 | 컴퓨터는 3칸, 스마트폰은 하단 메뉴로 전환되는 반응형 |

## 실행 방법 (내 컴퓨터에서 열어 보기)

Windows 기준입니다. [Node.js](https://nodejs.org)가 설치되어 있어야 합니다.

**방법 1: 더블클릭**
1. 폴더 안의 `시작.bat`을 더블클릭합니다.
2. 잠시 뒤 브라우저에서 `http://localhost:5000`이 열립니다.
3. 끄려면 까만 창을 닫습니다.

**방법 2: 명령어**
```
npm start
```
실행 후 브라우저에서 `http://localhost:5000`을 엽니다. 포트 번호는 `server.js` 맨 위의 `PORT`에서 바꿀 수 있습니다.

## 파일 설명

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 뼈대 |
| `style.css` | 디자인 (맨 위 색상 값만 바꿔도 분위기가 바뀜) |
| `app.js` | 메모·할 일·캘린더 기능 |
| `storage.js` | 브라우저 저장소(localStorage)에 읽고 쓰기 |
| `server.js` | 내 컴퓨터에서 열어 보기 위한 간단한 서버 |
| `시작.bat` | 서버를 켜고 브라우저를 여는 실행 파일 |
| `PRD.md` | 무엇을 만들지 정리한 설계 문서 |
| `vercel.json`, `.vercelignore` | Vercel 배포 설정 (서버 없는 일반 사이트로 올리고, 내 컴퓨터용 파일은 제외) |

## 알아둘 점

- 데이터는 **이 브라우저 안에만** 저장됩니다. 컴퓨터와 스마트폰은 서로 다른 데이터가 보이고, 주소가 바뀌면 기존 데이터가 보이지 않습니다.
- 브라우저의 기록·사이트 데이터를 삭제하면 메모가 사라질 수 있습니다. 백업(내보내기) 기능은 없습니다.
- 주민등록번호, 계좌번호, 비밀번호 같은 민감한 정보는 메모에 적지 마세요.

## 현재 상태

**완성** — 기본 기능(메모·할 일·캘린더)을 모두 만들었고, 배포와 컴퓨터·스마트폰 확인까지 끝났습니다.
AI 기능(메모 요약 등)은 필요하지 않다고 판단해 만들지 않았습니다. 나중에 필요해지면 [PRD.md](PRD.md)의 4장을 참고해 추가할 수 있습니다.
